# External API Integrations

1. Google Gemini — AI analysis and generation; authenticated with GEMINI_API_KEY.
2. Brevo — notification/email delivery; authenticated with BREVO_API_KEY.
3. Frankfurter — exchange-rate data; GET /api/external/exchange-rate; no application credential required.

Each integration should be demonstrated as Request → Authentication (where required) → Processing → Response → Error Handling.
